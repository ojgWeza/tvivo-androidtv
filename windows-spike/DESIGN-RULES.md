# WinUI design rules

- Orange (`#D97757`) is the app-wide accent. Keep `SystemAccentColor` and its light/dark variants, accent brushes, and control-state brushes in `src/Tvivo.App/App.xaml`; new controls inherit the same hover, pressed, checked, selected, and focus color rule. Do not set a Windows blue/gray accent on an individual control.
- Keep player selection visible as an orange row background. Do not replace it with a “now playing” status label.
- For player status, orange marks the selected/now-playing row. Favorite stars use the distinct gold `AppFavoriteBrush` when filled and muted text color when outlined, so favorite state remains distinguishable on an orange selected row.
- Transitions never rebuild visible content in place. Every category-tab path keeps the current catalog source attached while the next category snapshot loads, fades the current content out before applying the new snapshot, then fades it back in. Preserve the page instance and each category's scroll/interaction state.
- Artwork flows from `Channel.LogoUri` through `CatalogCard.ArtworkUrl` to `Image.Source` as a decoded `BitmapImage`; the image uses code-behind loading, not a XAML `Source` binding. Validate that the bound item still matches and the image is loaded/attached before assigning; reveal the decoded bitmap and collapse its placeholder at assignment, while `ImageOpened` records render confirmation. Keep the bounded decoded cache keyed by URL and decode size with least-recently-used eviction. Log item-scoped sanitized URLs, HTTP status, decode/apply/render results, and image failures without credentials or query values.
- The window caption buttons use the shared icon-only, transparent chrome style in `App.xaml`, with a subtle orange hover treatment. Do not leave window-control buttons on the platform default background style.
- Icon-only buttons use the shared `AppIconButtonStyle` in `App.xaml` (based on `AppCaptionButtonStyle`): transparent and frameless at rest, with a subtle orange hover/pressed highlight. Apply it to info, navigation, and other glyph-only actions instead of the platform default button chrome.
- During active fullscreen playback, show the mouse cursor on movement and hide it after three seconds of inactivity. Never hide it on catalog, menu, or windowed player screens.
- Keep plot and cast text out of fixed player columns. Show an info button beside the title and display the description in an overlay flyout so the episode or related-item list does not reflow.
- App buttons use the shared 12 px corner radius from catalog cards/tiles and comfortable shared padding. Orange primary buttons must retain that shape and sizing through the global app style.
