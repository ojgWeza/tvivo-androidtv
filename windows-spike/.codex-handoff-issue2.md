# Issue 2 handoff — playback restarts during buffering; unknown duration

## Root cause found

`MainWindow.PauseButton_Click` treated every `IsPlaying == false` state as a stopped player and called `StartPlaybackAsync`, which tears down/restarts the source. A buffering transition is also non-playing, so a pause/play action during buffering could restart playback. Separately, both engines exposed unknown duration as `0`; the UI displayed that sentinel as a real `0:00` duration and showed a one-millisecond seek range.

## Fix applied

- Added playback state signals (`IsBuffering`, `IsPaused`, `IsEnded`) and a `PlaybackTimeline` contract with nullable duration in `src/Tvivo.Core/Contracts.cs`.
- Implemented state reporting in both engines. FFmpeg playback now observes `MediaEnded`; both engine pause toggles only act on active or paused states. See `src/Tvivo.Playback/FFmpegInteropPlaybackEngine.cs` and `src/Tvivo.Playback/WindowsPlaybackEngine.cs`.
- Updated `src/Tvivo.App/MainWindow.xaml.cs` so buffering/paused playback toggles in place, ended playback can restart, and unknown duration renders as `—:—` with seeking disabled. Position remains available independently for Issue #4.

## Deviations and uncertainty

No scope deviation. No build, run, launch, or tests were performed, as requested. Changes are source-reviewed only; engine state/event timing and the UI behavior still need runtime validation. Duration is explicitly unknown when the engine reports no positive duration; no duration is inferred from unrelated catalog metadata.

## Next steps — Issue #4

Build rewind/forward controls on `IPlaybackEngine.Timeline`: clamp target positions to `0..DurationMilliseconds` when duration is known; when it is unknown, preserve elapsed position but disable duration-bounded seek controls. Keep buffering, paused, playing, and ended behavior distinct so seeking never routes through a playback restart. Relevant files: `src/Tvivo.Core/Contracts.cs`, `src/Tvivo.App/MainWindow.xaml.cs`, `src/Tvivo.App/MainWindow.xaml`, `src/Tvivo.Playback/WindowsPlaybackEngine.cs`, and `src/Tvivo.Playback/FFmpegInteropPlaybackEngine.cs`.
