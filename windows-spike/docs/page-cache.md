# Catalog page switch cache

`CatalogLandingPage` retains the rendered shelf view models for the last three visited top-level modes: For You, Movies, Series, and Live. An entry contains a catalog snapshot and its `ObservableCollection<ShelfRowViewModel>`. Search results and open folders use the existing snapshot path. The UI binds a valid collection in the same content frame and restores that mode's recorded scroll position without the mode-swap loading timer, the 32 ms load delay, or a content fade. The page then checks the persisted catalog refresh stamps in the background. It reads and applies a new snapshot only when the full revision changed; an in-mode update reconciles shelves in place.

## Keys and bounds

The Core `CatalogPageCachePolicy<TPage>` owns one account at a time and keys pages by mode. A revision includes the latest persisted catalog refresh stamp, Spotlight settings revision, UTC selection day, activity revision, and favorites revision. A revision mismatch clears all rendered entries. The LRU keeps at most three pages, and a new account, sign-out, shutdown, or artwork memory-pressure clear discards them. The older catalog snapshot cache remains independently bounded at eight entries and 64 MiB, and decoded artwork remains limited to 128 entries and 96 MiB. On page departure, decoded artwork outside loaded, visible images is released; inactive rendered entries hold view models and metadata, not decoded bitmaps or full-size off-screen artwork.

An async revalidation carries a generation token. A newer revalidation, invalidation, or account switch makes an older completion ineligible to update the page. Local catalog refresh completion invalidates rendered and snapshot entries before reading the refreshed catalog. Visit/favorite notifications also bump their revisions and invalidate rendered entries. Explicit Home entry still uses `CatalogScrollEntryPolicy.StartAtTop`; Back and ordinary mode switches restore each mode's scroll.

## Live check

Using an account with a populated catalog, visit For You → Movies → For You → Series → Movies. The second For You and Movies entries should appear from the retained view without a loading cover or fade and return to their own scroll positions. Inspect redacted `event=perf.page-switch` records for `from`, `to`, `cacheHit`, `clickToFirstPaintMs`, `dbReadMs`, `renderMs`, and `artworkMs` (milliseconds; `-1` means no artwork assignment was observed in the sampling window). Warm hits should have zero foreground DB read and much less foreground render time than misses. First paint is sampled on the next low-priority dispatcher turn, so a live visual check is still required for perceived paint, artwork, and scale. Refresh catalog, change Spotlight settings, record a visit, change a favorite, and switch tabs again to verify invalidation. Confirm explicit Home returns to the top while Back restores scroll. Do not open a provider stream during automated tests.
